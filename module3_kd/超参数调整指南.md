# 超参数调整指南

## 快速开始

```bash
# 1. 单次实验
python train_kd.py --config my_config.json --folds "1"

# 2. 网格搜索
python sweep.py --sweep my_sweep.json --folds "1"

# 3. CLI 快速覆盖
python train_kd.py --folds "1" --lr 0.0005 --temperature 5.0
```

**每次运行自动保存 `run_config.json`**，包含本次全部参数，方便回溯对比。

---

## 参数总览

### 一、知识蒸馏（★★★ 最高优先级）

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|
| `kd_method` | str | `"dkd"` | `"vanilla"`, `"dkd"` | KD 方法。vanilla 是 Hinton 原始 KD，dkd 解耦目标类/非目标类 |
| `temperature` | float | `3.0` | `1.0 ~ 10.0` | 温度。越高教师分布越"软"，非目标类的暗知识越明显。**过大（>8）会模糊到接近均匀分布** |
| `alpha_kd` | float | `0.7` | `0.3 ~ 0.95` | KD 损失占总损失的权重。1-α 是 CE（硬标签监督）的权重。**α 太小 → KD 不起作用，α 太大 → 学生忽略 ground truth** |
| `alpha_dkd` | float | `0.5` | `0.1 ~ 0.9` | 仅 DKD 有效。TCKD（目标类蒸馏）在 KD 项内的权重。**<0.5 偏重 NCKD（类间关系），>0.5 偏重 TCKD（目标类精确度）** |

**调整建议：**
- 第一轮：固定 `kd_method=dkd`，对 `temperature` × `alpha_kd` 做网格搜索
- 如果 Class 2/3 准确率低 → 调低 `alpha_dkd`（让 NCKD 更多传递类间关系）
- 如果整体偏弱 → 先试 vanilla KD 确认教师软标签质量，再切 DKD

---

### 二、学习率和优化器（★★★ 最高优先级）

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|
| `lr` | float | `0.001` | `1e-4 ~ 1e-2` | 初始学习率。**最重要的单个参数** |
| `momentum` | float | `0.9` | `0.8 ~ 0.99` | SGD 动量。SGD 时有效，AdamW 时忽略 |
| `weight_decay` | float | `5e-4` | `1e-5 ~ 1e-2` | L2 正则化系数。防止过拟合，但对小数据集可能抑制学习 |
| `optimizer` | str | `"sgd"` | `"sgd"`, `"adamw"` | 优化器。SGD+momentum 是 ResNet 标配；AdamW 收敛快但可能需要调更小的 lr |

**调整建议：**
- 先确定 optimizer，再调 lr
- SGD：lr 主搜 `[0.0005, 0.001, 0.005, 0.01]`
- AdamW：lr 主搜 `[1e-4, 3e-4, 1e-3]`
- weight_decay：过拟合时增大（1e-3），欠拟合时减小（1e-5）

---

### 三、学习率调度（★★ 中等优先级）

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|
| `lr_scheduler` | str | `"cosine"` | `"step"`, `"cosine"` | 调度策略。step=阶梯式衰减，cosine=余弦退火 |
| `lr_steps` | list | `[30, 60]` | 根据 epochs 定 | 仅 step 模式。在哪些 epoch 衰减 lr |
| `lr_decay` | float | `0.5` | `0.1 ~ 0.5` | 仅 step 模式。每次衰减的乘法因子 |
| `cosine_eta_min` | float | `0.0` | `0 ~ lr*0.01` | 仅 cosine 模式。最小学习率。0 表示自动设为 `lr × 1e-4` |

**调整建议：**
- 一般用 cosine 更省心（不用调 milestones）
- 如果用 step：`lr_steps` 设在 loss 平台期的位置（观察训练日志确定）
- cosine_eta_min 一般不用改，设为 0 即可自动

---

### 四、训练控制（★★ 中等优先级）

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|---|---|---|---|---|
| `epochs` | int | `90` | `30 ~ 150` | 总训练轮数。数据量小时可少，加 MixUp 后可多 |
| `batch_size` | int | `64` | `16 ~ 128` | 批大小。受内存限制。**对 KD 影响不大，但影响梯度稳定性** |
| `batch_size_test` | int | `128` | 同 batch_size | 测试批大小，一般设大一些加速评估 |
| `seed` | int | `42` | 任意整数 | 随机种子。**多 seed 取平均可衡量结果稳定性** |
| `eval_start_epoch` | int | `5` | `1 ~ 20` | 从第几个 epoch 开始测试评估。前几个 epoch 的评估意义不大 |

---

### 五、学生模型（★ 低优先级，但影响大）

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `student_arch` | str | `"resnet34"` | `"resnet18"`（11M, 快 2.4×）, `"resnet34"`（21M, 快 1.5×） |

**选择建议：**
- 追求部署速度 → ResNet-18
- 追求准确率 → ResNet-34（当前最佳 84.93%）
- ResNet-18 → ResNet-34 准确率提升约 2~3 个百分点

---

### 六、数据增强（★ 低优先级）

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `use_weighted_sampler` | bool | `true` | 类别均衡采样。**强烈建议开启**，对 Class 2/3 提升显著（+19%） |
| `use_mixup` | bool | `false` | MixUp 数据增强。将两张图和标签按比例混合 |
| `mixup_alpha` | float | `0.2` | MixUp 的 Beta 分布参数。**越大混合越强，0.1~0.4 常见** |
| `rotate_degrees` | int | `20` | 随机旋转角度范围（±度数） |
| `use_random_horizontal_flip` | bool | `true` | 水平翻转。医学图像通常可开 |

**注意：MixUp 和 WeightedSampler 互斥**，同时开启时 MixUp 不生效。

---

### 七、不推荐调整的参数

| 参数 | 原因 |
|---|---|
| `num_classes` | 固定为 4，任务定义 |
| `mean`, `std` | 训练集预计算值，改了对不上 |
| `resize_train`, `resize_test`, `crop_size` | ResNet 标准输入尺寸 |
| `num_workers` | Windows 下用 0 最稳定 |

## 推荐调参流程

### 第一轮：核心超参粗搜（~2 小时，单 fold 即可）

```json
{
    "search": {
        "lr": [0.0005, 0.001, 0.005],
        "temperature": [1.0, 3.0, 5.0],
        "alpha_kd": [0.5, 0.7, 0.9]
    }
}
```

跑 3×3×3 = 27 个实验，epochs 设 30-40 快速筛选。选出 top-3 组合。

### 第二轮：结构 + 正则化细调（~3 小时）

```json
{
    "search": {
        "student_arch": ["resnet18", "resnet34"],
        "weight_decay": [1e-4, 5e-4, 1e-3],
        "alpha_dkd": [0.3, 0.5, 0.7]
    }
}
```

用第一轮最佳 lr/T/α_kd 作为 base，epochs 设 60。

### 第三轮：增强 + 稳定性验证（~5 小时，需要多 fold）

```json
{
    "search": {
        "use_mixup": [false, true],
        "mixup_alpha": [0.1, 0.2, 0.4],
        "seed": [42, 123, 456]
    }
}
```

全 5 折跑最优配置，确认稳定性和泛化能力。

## 实验结果记录格式

每次运行自动在 `module3_output_kd/<timestamp>/run_config.json` 保存完整配置。分析结果时直接对比各目录的 `fold_X.jsonl`：

```python
import json
from pathlib import Path

for run_dir in Path('module3_output_kd').glob('*/'):
    config = json.load(open(run_dir / 'run_config.json'))
    # 找到最佳 fold
    best = 0
    for jsonl in run_dir.glob('fold_*.jsonl'):
        with open(jsonl) as f:
            lines = [json.loads(l) for l in f if l.strip()]
        for l in lines:
            if l.get('type') == 'summary':
                best = max(best, l['best_acc'])
    print(f'{run_dir.name}: lr={config["lr"]}, T={config["temperature"]}, '
          f'best={best:.4f}')
```
